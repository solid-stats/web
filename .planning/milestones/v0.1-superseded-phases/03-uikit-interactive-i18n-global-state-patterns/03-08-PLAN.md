<objective>
Close GAP-01 (blocker): the RU↔EN language toggle never renders, so EN is unreachable from the UI and SC#2 fails. `config.mjs` declares the toggle as `addons.control.defaultState.locale`, but in Ladle 5.1.1 `addons.control.defaultState` is only a per-STORY args seed — it is never injected into `globalState.control` (rebuilt from the active story's own args, wiped on every story switch). So `globalState.control.locale` is always `undefined` → `toLocale` falls back to `ru` forever [src: 03-UAT.md#GAP-01] [src: 03-UAT-VISUAL-FINDINGS.md#Blockers].

Purpose: make RU↔EN switchable from the Ladle UI so every catalogued story is verifiably bilingual (KIT-08 SC#2, QUAL-05). The `components.tsx` wiring (`toLocale`/`activate`/`I18nProvider`) is already correct — nothing creates the control it reads; this plan creates a real persistent locale source.

Output: a working persistent language switch + a regression test that fails on the dead `control.defaultState` declaration and passes once a real source is wired.
</objective>
