# Phase 3 — UI Design Contract

> Visual and interaction contract for the interactive half of the UIKIT (Ark UI form + overlay
> primitives), the typed RU/EN i18n harness (Lingui), and the reusable global-state patterns
> (SURF-18). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Scope note.** This is a UIKIT phase, not a single surface — it ships colocated Ladle stories in
> `packages/design/src/shared/uikit/`, not routes. The design SYSTEM is locked (DESIGN.md →
> `theme.css`); this contract pins how the new interactive primitives consume it and the
> per-component interaction/states contracts. The pipeline overlay is
> `solidstats-frontend-react-design`; the review overlay is `solidstats-frontend-react-design-review`.
>
> **Pre-populated from upstream — almost nothing was re-asked.** Sources: `DESIGN.md` (tokens,
> recipes), `packages/design/src/styles/theme.css` (emitted tokens), `03-CONTEXT.md` (D-01…D-07 +
> discretion), `_fixtures/strings.ts` (the RU/EN seed), `ROADMAP.md` Phase 3 SC#1–4,
> `REQUIREMENTS.md` (KIT-05/06/08, SURF-18, QUAL-01..05).

## Spacing Scale

Tailwind's **stock 4px scale** (DESIGN.md: no custom keys). Dense defaults: 8/12/16 dominate;
24/32 separate major regions. The template's named tiers map onto the stock utilities:

| Token | Value | Tailwind | Usage in this phase |
|-------|-------|----------|---------------------|
| xs | 4px | `p-1` / `gap-1` | icon↔label gap inside a control (`gap-1` = 4px on the `control` base) |
| sm | 8px | `p-2` / `gap-2` | field label↔input gap, menu item padding, tooltip padding |
| md | 16px | `p-4` / `gap-4` | default field/dialog body padding, stack gap between form fields |
| lg | 24px | `p-6` / `gap-6` | dialog padding, section padding |
| xl | 32px | `p-8` | major region separation |
| 2xl | 48px | `p-12` | (rare in primitives) major section breaks |
| 3xl | 64px | `p-16` | (rare in primitives) page-level — N/A in Ladle stories |

Exceptions: **44px minimum hit area** (`min-h-11`) on every interactive control — WCAG 2.2 AAA 2.5.5,
owned by the `control` base recipe and re-asserted on every new Ark trigger/option/tab. Not a spacing
exception per se (it is a min-height floor), recorded here because it overrides intrinsic control
height. `2px` sub-step (`p-0.5`) is allowed (stock scale).

## Typography

The full scale + roles live in `DESIGN.md typography` and `theme.css`. This phase's interactive
primitives consume a **4-size scale {12, 14, 18, 22}** at **2 weights {400 regular, 600 semibold}**
only. Tabular alignment of numbers comes from the **monospace font face**, not from weight — so the
mono/stat role is 400 at 14px (no 500 medium, no separate 13px step):

| Role | Size | Weight | Line Height | Family | Applied to |
|------|------|--------|-------------|--------|-----------|
| body (default UI) | 14px (`text-base`) | 400 regular | 1.5 | IBM Plex Sans | input value text, menu items, dialog body, tab labels |
| label | 12px (`text-xs`) | 600 semibold | 1.5, `letterSpacing.label` 0.06em, uppercase | IBM Plex Sans | field labels, column-header-style labels |
| caption | 12px (`text-xs`) | 400 regular | 1.5 | IBM Plex Sans | helper text, char counts (use `text-muted`, never `text-subtle` for meaningful copy) |
| dialog title / heading | 18px (`text-lg`) | 600 semibold | 1.25 snug | IBM Plex Sans | Dialog title, Popover heading |
| section heading | 22px (`text-xl`) | 600 semibold | 1.25 snug | Exo 2 | StateMatrix section titles |
| stat / mono | 14px (`text-base`) | 400 regular | 1.5, tabular-nums | IBM Plex Mono | NumberInput/Stepper value (numbers align via the mono face, not weight) |

Rules carried in: error message copy uses the `body`/`caption` role at `text-loss` color **paired with
a Lucide icon** (never color-alone); placeholder uses `text-subtle` (the one sanctioned `text-subtle`
use); `2xs`/11px is reserved for provenance/meta in other phases and is NOT in this phase's primitive
contract.

## Color

The full palette is in `DESIGN.md colors` (locked, contrast-validated by `design.md lint`). The
60/30/10 split for this phase's primitives:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-0` `#0A0D13` / `bg-1` `#0F131C` | app backdrop, sticky surfaces, Ladle story base |
| Secondary (30%) | `surface-1` `#151A25` (panels, dialog body, popover, menu) · `surface-2` `#1B212F` (**input fill**, raised-in-card) · `surface-3` `#232B3B` (hover/active row, menu-item hover) | cards, inputs, overlays, hover states |
| Accent (10%) | `primary` cyan `#36C5E0` (+ `-hover` `#2FB9D4`, `-active` `#27A8C2`, `-weak`, `-border`) | see reserved-for list below |
| Destructive | `loss` `#FF5C6C` (+ `-weak`, `-border`) | inline field errors, error-state recovery affordance, any future destructive confirm |

**Accent (cyan) reserved for — explicit list (never "all interactive elements"):**
- focus ring (`--shadow-ring`) on every control and the input focus glow (`--shadow-ring-glow` +
  `primary-border` border)
- active/selected state: active Tab, active Menu item, selected Select option, segmented active member
- primary-action buttons (`button-primary`)
- links / "how it's computed" provenance link
- the cyan-tinted selected-row marker (`primary-weak` fill + inset `primary` left edge)

Cyan is kept **rare** so it stays meaningful (DESIGN.md Do's). Semantic colors (`win`/`loss`/`warn`/
`info`) appear in this phase only via composed global-state recipes (SURF-18 banners reuse the
existing `DataTrustBanner` `BannerKind`) and inline form errors (`loss`) — **always paired with a
Lucide icon and/or label, never color-alone** (QUAL-03).

## Copywriting Contract

All copy is **typed RU/EN** through the **Lingui** catalog (KIT-08), which **migrates the existing
`_fixtures/strings.ts` `STRINGS` seed** — RU primary, EN at parity (D-03, QUAL-05). ICU plural
(RU one/few/many) and interpolation (`{n}`, `{from}–{to} из {total}`, `{col}`, `{id}`) are exercised
now. New keys this phase introduces (in addition to the migrated Phase-2 keys), with RU primary / EN
mirror:

| Element | Key (proposed) | RU | EN |
|---------|----------------|----|----|
| Primary CTA (form submit — demo form) | `formSubmit` | Отправить | Save changes |
| Form cancel / dismiss | `formCancel` | Отмена | Go back |
| Select placeholder | `selectPlaceholder` | Выберите… | Select… |
| Input required hint | `fieldRequired` | Обязательное поле | Required |
| Field error — generic user error (by-field) | `fieldErrorRequired` | Заполните это поле | Fill in this field |
| Stepper increment / decrement aria | `stepperIncrement` / `stepperDecrement` | Увеличить / Уменьшить | Increase / Decrease |
| File upload dropzone | `uploadDropzone` | Перетащите изображение или выберите файл | Drop an image or browse |
| File upload browse button | `uploadBrowse` | Выбрать файл | Browse |
| File upload reject (type/size) | `uploadRejected` | Только PNG/JPEG/WebP до {max} | PNG/JPEG/WebP only, up to {max} |
| Dialog close aria | `dialogClose` | Закрыть | Close |
| Tooltip / popover trigger aria (when icon-only) | per-use `*Aria` | (per control) | (per control) |
| Language switcher aria | `navLanguageAria` (exists) | Сменить язык | Switch language |
| Toast dismiss aria | `toastDismiss` | Закрыть уведомление | Dismiss notification |
| Empty state heading (global pattern) | `emptyTableHeading` | Пока нет игроков | No players yet |
| Empty state body (global pattern) | `emptyTableBody` (exists) | Игроки появятся здесь после первого пересчёта. | Players appear here after the first recompute. |
| Error state (system error — id + contact) | `errorSystem` (exists) | Не удалось загрузить. Код: {id}. Сообщите нам, если повторяется. | Could not load. Ref: {id}. Contact us if it persists. |
| Loading (cold aggregate) | `loadingColdAggregate` (exists) | Пересчитываем агрегат… | Recomputing aggregate… |
| Offline / reconnecting / stale banners | `offlineBanner` / `reconnectingBanner` / `staleBanner` (exist) | (see strings.ts) | (see strings.ts) |

**Error copy rule (errors.md):** distinguish *user* error (sits by the field, names the fix — e.g.
`fieldErrorRequired`) from *system* error (carries a request/debug `{id}` + a contact path — e.g.
`errorSystem`). No raw error strings; UI maps stable codes → localized copy.

**Destructive actions in this phase:** none ship as real product flows (no surfaces here). The
Dialog primitive must demonstrate a **destructive-confirmation pattern story** (reversible / checked /
confirmed, WCAG 3.3.6) for Phases 8–9 to compose — confirm button uses `loss`, paired with an icon
and an explicit verb+noun label, focus defaults to the safe (cancel) action.

**RU length check (QUAL-05):** RU runs longer than EN — verify the longest RU label
(«Перетащите изображение или выберите файл», «Войти через Steam») does not clip or wrap badly in the
narrowest container; stack label-over-value where needed. Sanity-check every new RU string reads
naturally, not machine-literal.

## Component Inventory & Interaction Contracts

The durable Ladle deliverables this phase graduates into `packages/design/src/index.ts`. Each is a
PascalCase `shared/uikit/<Component>/` slice: Ark headless primitive + `tv()` recipe consuming
`@theme` tokens, controlled props in, `data-*` test hooks, **no business/i18n imports inside the
primitive** (architecture.md uikit boundary; D-01). Each demonstrated **two ways** (D-02): a static
`StateMatrix`/`StateCell` grid (screenshot + axe + 44px gate, forced open/validation cells) **and** an
interactive Ladle `Playground` story exercising Ark's real keyboard/focus runtime.

### KIT-05 — Form family

| Slice | Ark base | Contract |
|-------|----------|----------|
| `Field` | (wrapper) | Owns the **visible label**, helper text, **inline error**, and `aria-live` live-region shared across fields. Label is real `<label>` associated to the control; error announced, sits by the field, includes recovery copy. No naked inputs. (Discretion: one shared wrapper vs split-per-control — planner's call.) |
| `Input` | Ark Field / native input styled | `input` recipe: `surface-2` fill, `border-1` hairline → `border-2` on hover → `primary-border` + `ring-glow` on focus-visible; `text-subtle` placeholder; disabled = `surface-1` + `text-subtle` + 0.6 opacity. |
| `Select` | Ark Select | Options typed by their value union (not `SelectOption<string>`); placeholder `selectPlaceholder`; active option cyan; popover content on `surface-1` + `border-2` + `--shadow-md`; full keyboard (arrows/Home/End/type-ahead), no trap. |
| `Stepper` | Ark NumberInput | Value in tabular mono (`stat`/`mono` role — 14px/400, alignment from the mono face); inc/dec controls ≥44px with `aria-label`; (discretion: own slice vs `NumberInput` variant). |
| `FileUpload` | Ark FileUpload | Image evidence + external link; **keyboard-accessible dropzone** (focusable, Enter/Space opens picker, explicit Browse button — not a div-only drag target); drag-over announced not color-only; per-file pending/success/error/retry; rejection states *why* + fix; revoke object URLs on unmount; **disallow SVG**; client validation is UX only (real gate is `server-2`, v1.0). (security.md). |

Forms compose under **TanStack Form** in v1.0 (forms.md) — this phase ships the presentational
primitives + the `Field` live-region seam only; live-after-submit validation behavior is demonstrated
as a story state, not wired to a real mutation.

### KIT-06 — Overlay family

| Slice | Ark base | Contract |
|-------|----------|----------|
| `Dialog` | Ark Dialog | `dialog` recipe: `surface-1` + `border-2` + `rounded-xl` + `--shadow-lg`, `overlay` scrim; portal; localized title (real heading); controlled open + lazy mount; **focus trap inside, focus returns to trigger on close, Esc closes**; inerts main content; close affordance with `dialogClose` aria. |
| `Menu` | Ark Menu | `popover`-style surface; `aria-expanded`/`aria-controls` on trigger; arrow/Home/End keyboard; item hover `surface-3`, active cyan; ≥44px items; Esc closes; no trap. |
| `Tabs` | Ark Tabs | Active tab cyan + the cyan is paired with selected state (never color-alone); arrow-key roving tabindex; focused tab never obscured under a sticky bar (2.4.12); panel association via aria. |
| `Tooltip` | Ark Tooltip | Not a substitute for a label; on focus as well as hover; respects `prefers-reduced-motion`; never the only carrier of meaning. |
| `Popover` | Ark Popover | `popover` recipe: `surface-1` + `border-2` + `rounded-lg` + `--shadow-md`; focus-managed, returns focus, Esc closes, no trap. |

All overlays: **keyboard-accessible, focus-managed, no traps** (ROADMAP SC#1); animate
`transform`/`opacity` only (CLS = 0); floating UI is the only place shadow is used (DESIGN.md
Elevation).

### KIT-08 — i18n harness + language switcher

- **Lingui** in framework-agnostic **core mode** (`@lingui/core` + `@lingui/react`), no router
  coupling (D-03). Typed keys (missing key = `tsc` error), ICU message syntax, **RU/EN parity
  enforced**. Migrates `STRINGS` → Lingui catalogs; RU primary.
- **Language switcher** wired as a Ladle global control/addon + a Lingui `I18nProvider` in
  `.ladle/components.tsx` so every story renders from the catalog and toggles RU↔EN (D-04). The
  switcher control itself is icon-or-label with `navLanguageAria`.
- Plurals: RU one/few/many via ICU `plural`, never string concatenation. Numbers/dates localized
  (decimal comma in RU) where they appear.

### SURF-18 — Global-state patterns + AsyncBoundary

- Delivered as **reusable story-level recipes composing existing Phase-2 primitives** (`Skeleton`,
  `EmptyState`, `ErrorState`, `DataTrustBanner`) into the six named states — **loading / empty /
  error / offline / reconnecting / stale** — **plus one thin `AsyncBoundary`-style wrapper slice**
  mapping a state union → the right primitive (D-05). Underlying primitives are **not** rebuilt
  (they already encode CLS-0 reservation + icon+text, never color-alone). `DataTrustBanner.BannerKind`
  already maps offline/reconnecting/stale; it has a `reserved` same-height kind for CLS = 0.
- Every state **reserves its final height** and **never relies on color alone** (QUAL-03/04). The
  **CLS = 0 contract is scoped by block role** (GAP-03 — the earlier "all six states the same
  reserved height as ready" was an over-claim that wrongly height-compared the 40px status banners
  against the table content region):
  - **Content-region states — `loading` / `empty` / `error` / `ready`** — occupy the same content
    region. The swap the user actually sees is **`loading` ↔ `ready`**, which **MUST reserve
    byte-for-byte the SAME box** (the loading `Skeleton variant="table"` ≡ the real KIT-02 `Table`
    the ready slot renders — both `tableViewportHeight(rows, ROW_H)` inside the identical bordered
    card; the 1px hairline GAP-03 caught is closed). **Decision:** `empty` / `error` are
    **intentionally content-sized**, NOT padded to the table region's height — they route to
    `EmptyState` / `ErrorState`, whose own `min-h-48` reservation is their CLS guarantee. They are
    a deliberate, honest "nothing here / something broke" surface at their own intrinsic height, not
    a forced match to the table box. The CLS-equality *measured set* is therefore `loading ≡ ready`.
  - **Status banners — `offline` / `reconnecting` / `stale`** — are a **separate block role**: a
    40px `DataTrustBanner` strip above/around content, **NOT height-compared to the content region**.
    Their CLS guarantee is the `DataTrustBanner` reserved-height invariant (its own `reserved`
    same-height kind, proven by the `DataTrustBanner CLS = 0` spec block).
- `AsyncBoundary` prop shape (discriminated state union vs slots) and slice granularity is
  **Claude's discretion** — planner reconciles against architecture.md slice rules; D-05 is the
  intended shape, not a rigid file count.

### Toast manager (deferred from Phase 2)

- Build the deferred Toast lifecycle (trigger / portal / queue / auto-dismiss / stacking) on Ark UI
  `createToaster`, wrapping the existing presentational `Toast/Toast.tsx` as the visual leaf (D-06);
  interactive Ladle `Playground` with trigger buttons (`createToaster` mounts its own portal — no app
  shell). If `createToaster` cannot slot the existing styled markup (`render`/`asChild` limits), the
  planner flags it (research item #1). Dismiss control carries `toastDismiss` aria.

## Per-Component States & Quality Gates (QUAL-01..05)

Every interactive story demonstrates (D-07; ROADMAP SC#1, #4):

- **Component states ×7:** enabled / hover / pressed / focused / selected / disabled / loading —
  rendered AND visually distinct; a forced `StateMatrix` cell must mirror the live recipe (use the
  `FORCED_STATE` `!`-override precedent so a forced cell doesn't lose to the base in the merge-free
  `/lite` build; keep a `*.test.ts` asserting forced ≡ live).
- **Scenario endings ×5** where applicable: success · error (system: id+contact / user: by-field) ·
  loading (reserved-height skeleton) · onboarding · empty (actionable copy + count).
- **Data-volume ×4** for any list/field (Select options, FileUpload files, Menu items): empty · few ·
  many · limit-reached.
- **Click zone** defined (whole row beats text where rows are interactive).
- Forms: visible labels + inline errors + live-region feedback.
- Overlays: focus-managed, no traps, Esc-to-close, `aria-expanded`/`aria-controls`.
- **axe-clean** (`@axe-core/playwright`), **keyboard-operable**, **≥44px targets** (2.5.5),
  **visible focus** (2.4.13 / 2.4.7), **focus not obscured** (2.4.12), **never color-alone**,
  **`prefers-reduced-motion`** honored (2.3.3).
- **CLS = 0** — every async/overlay region reserves space; animate `transform`/`opacity` only.
- **RU + EN** both render and read naturally (QUAL-05) — RU sanity-checked for clipped/awkward wording.

The Phase-2 Playwright-against-Ladle + axe harness is **extended with per-component behavior specs**
(D-02): trap-free Tab cycle, Esc-to-close, `aria-expanded`/`aria-controls`, form live-region
announcements. Static-grid forced-open / forced-validation mechanics for the axe gate are an execution
detail (CONTEXT research item #3 — Ladle 5.1.1).
