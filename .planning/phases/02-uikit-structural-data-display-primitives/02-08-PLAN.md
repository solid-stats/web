diverged from the binding hi-fi `.design/hifi/shell.jsx`: NavBar is a flat single
row with no Brand / search / language / right-aligned account; account is player-only;

hi-fi `signedIn` boolean. The hi-fi is the binding semantic/layout reference (D-11):
diff against it, re-implement with project tokens — never port the JSX.

Purpose: GAP-01/02/03/04/05 closure (KIT-01 + QUAL-02 + QUAL-03).
Output: a reworked NavBar (three zones), universal account cluster, raised breakpoint
+ overflow strategy, a 5-tab MobileTabBar, a reveal-safe SkipLink + a test that cannot
pass while clipped.
</objective>
