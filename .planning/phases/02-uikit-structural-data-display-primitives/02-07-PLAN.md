<objective>
GAP-19 enabler. Introduce a shared interactive base primitive — `Button` (variants
primary / secondary / ghost / segment, sizes sm / md, ≥44px hit area, ONE canonical
focus ring) and `Link` (the `<a>` affordance sharing the same recipe) — and refactor
the hand-rolled controls scattered across the Phase-2 catalog onto it. Today every
interactive control re-implements the ≥44px hit area + the
`focus-visible:shadow-(--shadow-ring)` ring + surface/hover tokens by hand, and the
Toast action has already drifted to a different ring (`focus-visible:outline-*`). This
plan centralizes that into one primitive and removes the duplication.

Purpose: GAP-19 closure (the user's "почему нет базовых элементов? кнопки, ссылки…").
This lands FIRST because the nav-shell rework (02-08) and the data-table fixes
(02-09 / 02-10) refactor their controls onto this base — it is the enabler wave.

Output: a `Button`/`Link` slice graduated into the barrel; the ~7 hand-rolled controls
refactored to consume it with their visual contract unchanged.
</objective>
