<threat_model>
## Trust Boundaries

No runtime trust boundary — presentational fixture-only catalog. Role-aware nav *slots* are visual only; denied items are simply absent from the passed list — NO access-control enforcement here (RBAC is v1.0). [src: 02-RESEARCH.md#Security-Domain]

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | RU+EN nav labels rendered from fixtures | mitigate | All copy via JSX auto-escaping; never `dangerouslySetInnerHTML`; static literals (V5). [src: 02-RESEARCH.md#Security-Domain] |
| T-02-02 | Tampering | Lucide nav icons | mitigate | Icons via `lucide-react` components, never raw SVG strings (V14). [src: 02-RESEARCH.md#Security-Domain] |
| T-02-AC | (Access Control — informational) | role-aware nav slots | accept | Visual-only slot mechanism; no enforcement this phase. The denied-items-absent pattern is presentation, not authorization — RBAC enforcement is the v1.0 app milestone (route/loader gate). Documented so a reviewer does not mistake the visual slot for a security control. [src: 02-UI-SPEC.md#KIT-01] |
| — | Spoofing / Repudiation / Info-disclosure / DoS / Elevation | — | N/A | No auth/session/network/persistence/privilege this phase. [src: 02-RESEARCH.md#Security-Domain] |
</threat_model>
