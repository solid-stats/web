# Sketch Manifest

## Design Direction

Solid Stats should use the **Olive Ledger** direction: a calm dark statistics ledger with olive/stone surfaces, readable dense tables, restrained green accents, and condensed headings. It should feel serious, durable, and data-first rather than flashy, decorative, or betting-aggressive.

## Reference Points

- Product brief: mobile-first esports ops, not a landing page.
- Public visitor journey: table filters, sort, deep scroll, detail open, browser Back with state preserved.
- Moderator and request flows: visible but secondary to public stats in the first viewport.
- Selected palette/font direction: `08 Olive Ledger` from `.planning/sketches/palette-options/index.html`.
