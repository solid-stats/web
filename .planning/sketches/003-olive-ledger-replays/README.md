# Sketch 003: Olive Ledger Replays

## Design Question

How should the default Solid Stats page open on replay search/listing, and how should a specific replay result page summarize parsed outcomes?

## How to View

Open `.planning/sketches/003-olive-ledger-replays/index.html` in a browser.

Open `.planning/sketches/003-olive-ledger-replays/index.html?view=detail` to jump directly to the replay result state.

## Scope

This sketch makes `Реплеи` the default active navigation item. It includes two prototype states in one file:

- Replay list/search page.
- Replay result/detail page for a selected replay.

## What to Look For

- Whether the product makes sense when it opens on replay lookup by default.
- Whether the replay result page exposes enough parsed context without becoming an admin/debug page.
- Whether list-to-detail navigation feels simple and predictable.
