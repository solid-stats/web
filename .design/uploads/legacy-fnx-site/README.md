# Legacy FNX stats site — reference snapshots

Saved HTML exports of the pre-Solid-Stats fan-made statistics site ("FNX" stats), covering:

- `SolidGames Stats 2024 by FNX.html`, `Players stats.html` — personal player stat pages
  (rotations back to 2020, per-period Убийства/K-D/Счёт).
- `Squad stats.html`, `SolidGames - Отряды.html` — squad-level stats.

These are the workflow Solid Stats replaces (see the product brief's "Solid Stats replaces Google
Forms and file-based stat browsing"). Kept as reference for feature/data parity, not as design
output — do not treat as Claude Design or `.design/hifi/` material.
